# AEGIS
Hello everyone! I'm an individual participant in Catalyst 2026, and this is my project, AEGIS — Global Weather and Crisis Intelligence.

The problem I wanted to address is simple: weather information is widely available, but understanding what those conditions could mean for local communities is equally important.

AEGIS uses live weather data from Open-Meteo and processes it through a custom backend built using Python and FastAPI.

Here, users can search for a city and see its current weather conditions, including temperature, humidity, wind and precipitation.

The risk engine applies transparent, rule-based thresholds to identify potential weather-related concerns.

The dashboard also provides a five-day forecast to help users understand upcoming conditions.

Users can also select a location directly on the map using a pin and manually enter a temperature to calculate a temperature-only heat-risk indicator.

This is an experimental screening tool, not an official disaster warning.



My vision for AEGIS is to make weather intelligence more understandable and useful for schools and communities, supporting better preparedness.

I developed this working prototype during the seven-hour Catalyst build challenge, bringing together backend development, APIs and frontend engineering.

Thank you for watching. This is AEGIS.
